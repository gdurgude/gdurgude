# Exact-look GitHub profile package

This version intentionally uses image panels made from your supplied reference design.

Why:
GitHub README pages strip custom CSS and JavaScript. A normal Markdown/HTML README cannot reproduce that mockup pixel-for-pixel. Image panels are the most reliable way to preserve the visual design.

Files:
- README.md
- assets/01-hero.png
- assets/02-about.png
- assets/03-composing.png
- assets/04-projects.png
- assets/05-instruments.png
- assets/06-live-motion.gif
- assets/07-pulse.png
- assets/08-connect-footer.png

Upload README.md and the whole assets folder to your profile repository and replace the old versions.

Important:
The GitHub Pulse numbers in the reference image are visual placeholders from the mockup. If you want, regenerate that panel later with your real numbers.
