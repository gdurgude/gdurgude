## About me

I'm an **AI/ML software engineer** who likes owning the whole path from a rough idea to something a real person can use. That usually means an LLM or a voice model in the middle, a dependable **Python / TypeScript** backend underneath, and a clean **React** interface on top.

I've built tool-calling agents, real-time voice assistants and data pipelines, and I care about the unglamorous parts too: testing, evals, debugging production issues and making sure things fail gracefully. Off the clock I play piano and write my own melodies. To me, code and music are the same craft.
