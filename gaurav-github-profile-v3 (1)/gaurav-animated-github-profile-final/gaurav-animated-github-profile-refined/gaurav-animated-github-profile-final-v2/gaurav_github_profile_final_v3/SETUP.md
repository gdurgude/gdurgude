# Setup

1. Create/use the public profile repository `gdurgude/gdurgude`.
2. Upload every file from this folder to the repository root, keeping `.github/workflows/github-snake.yml` in the same nested path.
3. Commit the files.
4. Open **Actions** on GitHub and run the snake workflow once.
5. If an updated SVG looks cached, bump the `?v=14` value in README image references to `?v=15`.

This version already includes your real GitHub, LinkedIn, email, Instagram, and linked project names.
The animated SVGs use CSS/SMIL only; no JavaScript is required in the README.
