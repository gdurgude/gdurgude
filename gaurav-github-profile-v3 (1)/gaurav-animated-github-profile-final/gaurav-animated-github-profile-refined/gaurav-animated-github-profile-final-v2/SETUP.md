# Setup

1. Create/use the public profile repository `gdurgude/gdurgude`.
2. Upload every file from this folder to the repository root, keeping `.github/workflows/github-snake.yml` in the same nested path.
3. Replace `YOUR_INSTAGRAM` in `README.md` and `connect.svg` with your real Instagram username.
4. Commit the files.
5. Open **Actions** on GitHub and run the snake workflow once.
6. If an updated SVG looks cached, bump the `?v=12` value in README image references to `?v=13`.

The animated SVGs use CSS/SMIL only; no JavaScript is required in the README.
