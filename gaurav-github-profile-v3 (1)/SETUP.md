# V3 setup

Upload `README.md` and the entire `assets/` folder to your GitHub profile repository.

This version is intentionally built as multiple independent SVG/GIF sections, not one screenshot.
That gives you the screenshot-like visual style while keeping the README modular and easier to update.

GitHub limitations:
- GitHub strips custom CSS and JavaScript from README files.
- Local SVG/PNG/GIF images are reliable.
- The animated piano uses a GIF so it will keep moving on GitHub.
- If an SVG does not render immediately after upload, hard refresh after the commit finishes.

Before publishing, replace the placeholder portfolio text in `connect.svg` later if you want a real portfolio URL shown.
